# 🖥️ Subsystem: Frontend Architecture, DM Workspace & Forge (`client/src/app/`)

## 📌 Overview
The Angular 19 frontend uses a standalone component architecture powered by **Angular Signals** for reactive state, pure TypeScript rule helpers in `core/rules/`, a custom dark "Phyrexian" UI component library in `shared/ui/`, and real-time WebSocket synchronization.

> [!NOTE]
> For detailed documentation on the **Player Sheet & Companion (`client/src/app/features/player/`)**, see **[Player Companion & Character Sheet](client-player.md)**.

## 🧠 Core State, Rules & Interceptors (`client/src/app/core/`)

### 1. Reactive State & Domain Services (`core/services/`)
| Service | Responsibility |
| :--- | :--- |
| [`character-state.service.ts`](../../../client/src/app/core/services/character-state.service.ts) | Single source of truth for the hero vault (`characters`, `activeCharacter`, `dndEdition`, `vaultStatus`). Implements `ensureLoaded()` with `shareReplay(1)` to prevent duplicate fetches, `upsertCharacter()` to patch state in-place without full reloads, and persists both the active hero ID (`phyrexian_forge_active_char`) and active ruleset edition (`phyrexian_forge_active_edition`) in `localStorage` across refreshes (cleared on `reset()`). |
| [`websocket.service.ts`](../../../client/src/app/core/services/websocket.service.ts) | Manages `/ws/campaigns/{name}` lifecycle, sends the initial `{type: "auth", token}` frame upon connection, and streams typed live events (`roll_request`, `roll_result`, `whisper`, `vtt_update`, `party_update`, `presence`). |
| [`settings.service.ts`](../../../client/src/app/core/services/settings.service.ts) | Manages per-user AI model selection (Gemini free tier vs. Claude models) and user-supplied Anthropic API keys (`/api/v1/settings`). |
| [`admin.service.ts`](../../../client/src/app/core/services/admin.service.ts) | Admin dashboard queries: paginated user list, role promotion/demotion, deletion, and system activity metrics. |
| [`dice.service.ts`](../../../client/src/app/core/services/dice.service.ts) & [`roll-toast.service.ts`](../../../client/src/app/core/services/roll-toast.service.ts) | Orchestrates dice expression evaluation, advantage/disadvantage modes, 3D dice triggers, critical hit animations, and save-for-half calculations in the dice tray. |
| [`spell-rules.service.ts`](../../../client/src/app/core/services/spell-rules.service.ts) & [`class-combat.service.ts`](../../../client/src/app/core/services/class-combat.service.ts) | Client-side lookups for spell scaling, concentration tracking, and class-specific combat riders (e.g. Sneak Attack, Rage, Divine Smite, Planar Warrior). |
| [`bestiary.service.ts`](../../../client/src/app/core/services/bestiary.service.ts) | Queries `/api/v1/bestiary` for official SRD and custom monsters with source filtering (`include_official`, `include_mine`, `include_community` defaulting to `false`), cloning, creation, visibility toggling, and deletion. |
| [`character-import.service.ts`](../../../client/src/app/core/services/character-import.service.ts) | Handles PDF character sheet upload (`/characters/import-pdf`) and JSON character import/export flows. |

### 2. Pure Client Rules Engine (`core/rules/`)
Pure, deterministic TypeScript functions tested in isolation that mirror `backend/services/stats_service.py`:
- [`ability.ts`](../../../client/src/app/core/rules/ability.ts), [`hit-points.ts`](../../../client/src/app/core/rules/hit-points.ts), [`skills.ts`](../../../client/src/app/core/rules/skills.ts): Ability modifiers, edition detection (`is2024Edition`), `effectiveExhaustionLevel`, `isDeceasedByExhaustion`, `exhaustionD20Penalty`, `hasExhaustionDisadvantage`, `resolveRollMode` (5e Adv/Dis cancellation), `abilityCheckModifier`, normalized `isSaveProficient` + `savingThrowModifier` (mirroring *Diamond Soul*, *Slippery Mind* WIS + 2024 CHA, *Aura of Protection*, *Soul of Artifice* gated on `!magic_items_suppressed`), `hasReliableTalent` (2014 Rogue L11 vs 2024 Rogue L7), `passivePerceptionOf`, `passiveInvestigationOf`, `passiveInsightOf`, `describeDmModifiers`, proficiency bonuses, multiclass class/subclass summaries (`formatClassSummary`, `formatSubclassSummary`), HP bounds, and passive scores.
- [`spell-casting.ts`](../../../client/src/app/core/rules/spell-casting.ts) & [`spell-slots.ts`](../../../client/src/app/core/rules/spell-slots.ts): Upcast damage/healing dice scaling, spell attack crits, and slot consumption/recovery (including synchronized `pact.used` tracking).
- [`flexible-casting.ts`](../../../client/src/app/core/rules/flexible-casting.ts) & [`metamagic.ts`](../../../client/src/app/core/rules/metamagic.ts): Sorcerer spell slot $\leftrightarrow$ Sorcery Point conversions and Metamagic cost/effect rules.
- [`weapon-calc.ts`](../../../client/src/app/core/rules/weapon-calc.ts) & [`weapon-masteries.ts`](../../../client/src/app/core/rules/weapon-masteries.ts): Weapon to-hit/damage calculation supporting non-destructive `magic_items_suppressed`, signed `dm_modifiers`, `getAgonizingBlastBonus` (`+CHA` without double-counting), normalized `weapon.properties` (`string | string[]`), conditional weapon effects (e.g., *vs undead*, *vs fiend*), and 2024 mastery triggers.
- [`rest.ts`](../../../client/src/app/core/rules/rest.ts), [`class-resources.ts`](../../../client/src/app/core/rules/class-resources.ts), [`level-up.ts`](../../../client/src/app/core/rules/level-up.ts), [`recommendations.ts`](../../../client/src/app/core/rules/recommendations.ts): Short/Long Rest recovery rules (including multiclass hit die resolution `hitDieSize` / `availableHitDieOptions`, 2014 Sorcerer L20 *Sorcerous Restoration* `+4 SP` across `Sorcery Points`/`Sorcery Point`/`Font of Magic`, 2014 Bard `songOfRestDie` scaling `1d6`–`1d12`, and class resource pool resets), immutable class resource CRUD helpers (`upsertClassResourceList`, `setClassResourceCurrent`, `removeClassResourceAt`), level-up progression helpers, and Background/Species mandatory grants (`getBackgroundSkills`, `getBackgroundOriginFeat`, `getRacialSkills`, `getRacialBonusSkillCount`, `getMaxOriginFeats`).

### 3. Interceptors & Guards (`core/interceptors/`, `core/guards/`)
- [`jwt.interceptor.ts`](../../../client/src/app/core/interceptors/jwt.interceptor.ts): Attaches `Authorization: Bearer <token>` to outgoing API requests.
- [`error.interceptor.ts`](../../../client/src/app/core/interceptors/error.interceptor.ts): Normalizes HTTP errors (`401`, `403`, `409 Conflict`, `429 Rate Limit`) into user-readable notifications.
- [`auth.guard.ts`](../../../client/src/app/core/guards/auth.guard.ts) & [`admin.guard.ts`](../../../client/src/app/core/guards/admin.guard.ts): Route guards enforcing authentication and admin privileges.

## 🐉 DM Workspace & Virtual Tabletop (`client/src/app/features/dm/`, `campaigns/vtt-grid/`)

- **Entry Component:** [`dm.component.ts`](../../../client/src/app/features/dm/dm.component.ts) — Organized into two top-level Master Modes (`⚔️ Live DM` for `initiative`, `vtt`, `party`, and `notes`; `🛠️ DM Preparation` for `homebrew` Bestiary & Homebrew, `generators`, `prep`, and `entities`) with a pinned Active Combat Strip across non-initiative Live DM tabs.
- **Panels (`features/dm/panels/`):**
  - [`party-panel`](../../../client/src/app/features/dm/panels/party-panel): Live party HP, AC, passive scores, conditions, online presence, party-wide & per-member DM controls (`🔓 SR`/`LR`/`LU` 1-shot unlocks, `🏜️ Suppress Magic (Athas)`, Exhaustion stepper + `Waive Exh`, `✨ Insp`, `💀 DEAD (EXH 6)` indicator, and DM Check rolls using 2014 Disadvantage & `dm_modifiers`).
  - [`dm-modifiers-modal`](../../../client/src/app/features/dm/modals/dm-modifiers-modal): Per-hero modal controlling Exhaustion `0–6`, `Waive Exhaustion`, `Suppress Magic Items`, 10 signed numeric modifiers (`+/-`), and DM notes.
  - [`initiative-panel`](../../../client/src/app/features/dm/panels/initiative-panel): Turn tracker with automatic DEX tiebreaking, `🎲 Request Initiative` party prompt shortcut (which auto-seeds missing party members into combatants before incoming `roll_result` frames arrive), monster HP adjustments, condition toggles, and Unified Bestiary Quick-Add search with source filter chips (`Official`, `Mine`, `3rd-Party`).
  - [`entities-panel`](../../../client/src/app/features/dm/panels/entities-panel) & [`prep-panel`](../../../client/src/app/features/dm/panels/prep-panel): NPCs, villains, locations, monster statblocks, and AI session transcription/prep tools.
  - [`generators-panel`](../../../client/src/app/features/dm/panels/generators-panel) & [`homebrew-panel`](../../../client/src/app/features/dm/panels/homebrew-panel): AI encounter balancer (scaled to actual party levels), NPC & Riddle/Trap generators, Unified Bestiary explorer (with SRD cloning and private/public visibility toggles), and campaign homebrew forge.
- **Modals (`features/dm/modals/`):**
  - [`statblock-modal`](../../../client/src/app/features/dm/modals/statblock-modal): Renders structured monster statblocks (ability scores with modifiers, traits, and actions) with 1-click `[ 🎲 +X to Hit ]` and `[ 💥 XdY+Z Damage ]` rolls wired through `DiceService` and `RollToastService`.
  - [`roll-request-modal`](../../../client/src/app/features/dm/modals/roll-request-modal) & [`whisper-modal`](../../../client/src/app/features/dm/modals/whisper-modal): Dispatches targeted or party-wide WebSocket roll prompts (omitting the Stat selector and normalizing `stat: 'Initiative'` / `Initiative roll` Inbox labels for `initiative` requests, plus secret DM rolls) and private whispers.
  - [`paste-go-modal`](../../../client/src/app/features/dm/modals/paste-go-modal): AI extraction of raw pasted text into structured `CampaignEntitySchema` records.
  - [`loot-distribute-modal`](../../../client/src/app/features/dm/modals/loot-distribute-modal): Assigns items/currency directly to party member sheets.
- **Virtual Tabletop (`features/campaigns/vtt-grid/`):**
  - Integrated into the `🗺️ Tactical VTT Map` tab inside `Live DM` mode; features multi-scene battlemap canvas, authenticated `HttpClient` Blob loading (`DomSanitizer.bypassSecurityTrustStyle`) for JWT-protected `/api/v1/campaigns/{name}/assets/` map images with object-URL cleanup, grid calibration, size-scaled drag-and-drop token boundary clamping, hidden DM tokens, reactive `#fogCanvas` remount redraw on maximize, and interactive Fog of War polygon/cell reveal synced over WebSockets.

## 📐 Frontend Invariants
1. **Prevent `409 Conflict` on Saves:** Always update `CharacterStateService` from the HTTP response of `PUT /characters/{id}` (`tap(updated => ...)`), which carries the incremented `version` from the backend. Never fire concurrent uncoordinated full-sheet `PUT` requests with a stale `version`.
2. **No Polling for Live Campaign State:** Never poll REST endpoints for party HP, initiative, whispers, or VTT state; subscribe to `WebSocketService` streams.
3. **Pure Rules in `core/rules/`:** Keep mechanical math in `client/src/app/core/rules/` free of Angular DI or DOM dependencies so it remains unit-testable and deterministic (including 2024 `Artificer` prepared spells, `"Human (2024)"` origin feat count excluding half-races, multiclass `classes` feat summation, `Dart` finesse/global bonuses, and `char.skills` authority).
4. **Resilient Auth, Signal Isolation, Campaign Switch Guards & UI Primitives:** [`AuthService`](../../../client/src/app/core/services/auth.service.ts) preserves cached user sessions across transient 5xx/network outages while failing closed on 401/403 alongside [`authGuard`](../../../client/src/app/core/guards/auth.guard.ts). [`CharacterStateService`](../../../client/src/app/core/services/character-state.service.ts) reacts to edition changes on `[data-edition]` and clears active hero storage on `reset()`. [`HomebrewService`](../../../client/src/app/core/services/homebrew.service.ts) catches trailing `loadHomebrew` GET errors after write operations so committed mutations stay successful. [`NotesPanelComponent`](../../../client/src/app/features/dm/panels/notes-panel/notes-panel.component.ts) cancels pending 1500 ms debounced saves on `@Input() campaignName` change while [`DmComponent.onCampaignSelect()`](../../../client/src/app/features/dm/dm.component.ts) flushes pending drafts explicitly to the prior campaign. [`WebSocketService`](../../../client/src/app/core/services/websocket.service.ts) returns `boolean` send status and shows a rate-limited offline toast on failed non-ping transmits. Interactive forms/prompts/cards must follow [`design-contract.md`](../../../client/design-contract.md) using [`shared/ui`](../../../client/src/app/shared/ui/index.ts) directives/modals (`forgeInput`, `forgeSelect`, `forgeTextarea`, `<forge-modal>`, `[loading]`, `bg-panel` inside modals, max one `variant="primary"` per view, `ForgeConfirmService.askPrompt`) and theme tokens (`--theme-accent`, `red`, `gold`, `emerald`, `cobalt`).
5. **Forge Edition Parity & Model Defaults:** [`ForgeComponent`](../../../client/src/app/features/forge/forge.component.ts) scopes `raceOptions` (excluding 2024-only species such as `Warforged` from 2014 PHB selections while exposing full 2014 PHB races/subraces: `Variant Human`, `High Elf`, `Wood Elf`, `Dark Elf (Drow)`, `Half-Elf`, `Hill Dwarf`, `Mountain Dwarf`, `Lightfoot Halfling`, `Stout Halfling`, `Forest Gnome`, and `Rock Gnome`) and `bgOptions` (`backgrounds_2024.json` vs `2014`) to the active ruleset, resets incompatible `aiRace`/`aiBackground` selections to `'AI Choice'` inside `toggleEditionAndRefresh()` and `restoreAiDraft()`, and pre-fills Step 4 Origin Ability Adjustments from `RACE_2014_PRESETS` (including `Mountain Dwarf` `+2 CON / +2 STR` and automatic `+1` to all six stats for 2014 `Human` in `getFinalStat()`) / `BG_2024_PRESETS`. [`SettingsComponent`](../../../client/src/app/features/settings/settings.component.ts) aligns `DEFAULT_MODEL_OPTIONS` and `preferredModel` (`gemini-3.5-flash`) with [`config_loader.py`](../../../backend/core/config_loader.py).
