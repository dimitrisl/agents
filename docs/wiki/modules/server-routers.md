# 🚦 Subsystem: Server Routers (`server/routers/`)

## 📌 Overview
The `server/routers/` package defines all REST endpoints mounted under `/api/v1` and the WebSocket endpoint under `/ws`.

---

## 🔑 Key Routers

| Router | Prefix | Responsibility |
| :--- | :--- | :--- |
| [`auth_router.py`](file:///home/dimitrisl/Public/yet_another_dnd_project/agents/server/routers/auth_router.py) | `/auth` | User registration (`/register`), OAuth2 login (`/login`) with transparent legacy SHA-256 to PBKDF2 migration, demo accounts (`/demo`), profile (`/me`), tutorial state (`/tutorial`), rate-limited self-service password rotation (`/change-password` bumping `token_version` & clearing `must_change_password`), provider discovery (`/providers`), and optional Discord OAuth2 flow (`/discord/login`, `/discord/callback`, `/discord/exchange`). |
| [`character_router.py`](../../../server/routers/character_router.py) | `/characters` | CRUD operations for character sheets, campaign-homebrew hydration (`_get_homebrew_for_character`) on `GET ""` / `GET /{char_id}`, omitted-HP derivation via `stats_service`, `campaign_members` membership guards on `active_campaign`, tamper-proof preservation of DM/level fields in active campaigns on `PUT /{char_id}`, server-enforced `POST /{char_id}/short-rest` and `POST /{char_id}/long-rest` (respecting DM campaign 1-shot unlock locks & L6 death guards while permitting unrestricted Solo play), optimistic locking via `version`, portrait uploads (`/upload-portrait` saving to `data/portraits` with transactional aborted upload cleanup), custom portrait URLs, PDF import (`/import-pdf`), and PDF export (`/{char_id}/export-pdf` with SSRF redirect hardening). |
| [`campaign_router.py`](../../../server/routers/campaign_router.py) | `/campaigns` | Campaign management, name validation, party roster (hydrating carried weight & capacity via `sync_character_inventory`), member count aggregation, invite codes & rotation, DM state mutations (`PATCH /{name}/party/{char_id}/state` with synced re-calculation for exhaustion, bypass, Athas magic suppression, custom `dm_modifiers`, unlocks, inventory capacity, and Heroic Inspiration), party-wide unlock & Athas toggles (`POST /{name}/party/action-unlock`), edition-aware party long rest (`POST /{name}/party/long-rest`, skipping deceased L6 heroes), loot distribution (`POST /{name}/loot/distribute` hydrating item/weapon catalog weights), whispers with query isolation, roll requests (`_roll_in_secret` applying 2014 Disadvantage, Adv/Dis cancellation, `exhaustion_bypass`, and DM modifiers), player roll logging (`POST /{name}/rolls`), notes, encounters, entities, scenes, and cascading deletion with DM control reset. |
| [`forge_router.py`](../../../server/routers/forge_router.py) | `/forge` | AI character generation, portrait generation, manual creation enrichment (`POST /enrich-manual` including optional `chosen_class_choices` for 2014/2024 L1 class options), level-up analysis (`feat_metadata`, structured 2014 & 2024 class choices, 13-class `multiclass_options` + `HTTP 400` multiclass prerequisite enforcement & canonical class casing), and server-authoritative level-up application (`POST /level-up-apply`: enforces `dm_level_up_unlocked` and auto-relocks in active campaigns, blocks L6 deceased heroes, isolates primary subclass from new secondary classes, enforces `13+` multiclass prerequisites and single PHB bonus skill / Bard Musical Instrument picks via `HTTP 400`, cap 30 in 2024 Level 19+ across `dnd_edition`/`ruleset_version`, duplicate non-repeatable feat & half-feat option rejection via `HTTP 400`, and `prepared_spells` synchronization). |
| Static Mounts | `/api/v1/portraits` | Static files mount (`StaticFiles(directory="data/portraits")`) in `server/main.py` serving uploaded avatar images with unique UUIDs. |
| [`homebrew_router.py`](../../../server/routers/homebrew_router.py) | `/campaigns/{name}/homebrew` | Custom magic items, weapons, feats, and spells creation and campaign-scoped queries. |
| [`rules_router.py`](../../../server/routers/rules_router.py) | `/rules` | Static rules lookups (`classes`, `subclasses`, `feats`, `spells`, `races`, `backgrounds`, `items`, `weapon-masteries`, `class-choices`), case-insensitive class/subclass scaling resolution (`/classes/{name}/scaling`, `/combat-profile`), rules comparison, and AI Oracle. |
| [`session_router.py`](../../../server/routers/session_router.py) | `/campaigns/{name}/sessions` | Audio session transcription, text session recaps, prep ideas, and chronological journey graphs (`/journey` filtered to `is_revealed: True` for non-DM callers). |
| [`assets_router.py`](../../../server/routers/assets_router.py) | `/campaigns/{name}/assets` | Battle map, token, and DM-only Story Scene (`kind="scene"`) image asset uploads with URL-encoded campaign paths (`quote`), chunked streaming, 10MB limits, transactional cleanup on aborted uploads, path traversal protection, and anti-spoiler `kind="scene"` redaction/403 enforcement for non-DM callers on `POST` and `GET /assets`. |
| [`story_scenes_router.py`](../../../server/routers/story_scenes_router.py) | `/campaigns/{name}/story-scenes` | DM-only CRUD for narrative Story Scenes & visual cards (`require_campaign_role("dm")`), safe orphan asset cleanup, ephemeral party-wide or character-targeted `POST /{scene_id}/cast` WebSocket broadcasts (`scene_popup`), and remote `POST /dismiss` (`scene_popup_dismiss`). |
| [`settings_router.py`](../../../server/routers/settings_router.py) | `/settings` | Per-user AI model selection (Gemini free tier vs. Claude models) and BYOK Anthropic API key management (encrypted at rest via `server/secret_box.py`). |
| [`admin_router.py`](file:///home/dimitrisl/Public/yet_another_dnd_project/agents/server/routers/admin_router.py) | `/admin` | Admin-only user management (paginated list with `must_change_password` & `is_demo` flags, ReDoS-safe user search via `re.escape`, concurrent campaign counts via `asyncio.gather`, online status, one-time temporary password reset `POST /users/{id}/reset-password` with self/admin/demo protection & audit logging, cascade user deletion, and whisper moderation). |
| [`dm_router.py`](../../../server/routers/dm_router.py) | `/dm` | AI DM toolkit endpoints for encounter generation, monster tactical briefs, and loot generation. |
| [`bestiary_router.py`](../../../server/routers/bestiary_router.py) | `/bestiary` | Unified Bestiary endpoints combining scaled official 2014/2024 monsters in MongoDB (`official_monsters` collection with automatic fallback to static SRD rules) with custom DM monsters in MongoDB (`custom_monsters` collection). Supports source filtering (`include_official`, `include_mine`, `include_community`), cloning (`based_on`), visibility toggling (`PATCH /{id}/visibility`), and ownership-verified updates/deletions. |
| [`websocket_router.py`](../../../server/routers/websocket_router.py) | `/ws` | Real-time WebSocket connection manager, token/role verification, audience targeting, and VTT event broadcasting. |
